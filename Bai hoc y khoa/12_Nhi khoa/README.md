Thư mục chứa các bài học Nhi khoa thực chiến, bám sát khung **Core 45** tại `_CURRICULUM_NHI_KHOA.md`.

## Cấu trúc lưu trữ mỗi bài
Mỗi bài học sẽ gồm:
- **`PED-xx_<Ten_bai>.md`**: File bài học chính theo chuẩn *Why-based lesson style* (Làm gì + Tại sao làm vậy; trích dẫn guideline BV Nhi Đồng 1/2, Bộ Y tế, Nelson, AAP, PALS).
- **`PED-xx_<Ten_bai>.cards.json`**: Bộ câu hỏi trắc nghiệm/flashcard lâm sàng.
- **`PED-xx_<Ten_bai>.apkg`**: Gói Anki deck Pastel tương thích AnkiDroid/AnkiMobile.
